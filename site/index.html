UAC Portable Doom launcher

DOOMNITE

Sixteen games. Thirty-one launch configurations. One folder with the engine, the IWADs and every mod — and not one absolute path inside it. Copy it to a USB stick, plug it in anywhere, play.

Nothing to install first. The app ships with its own Python runtime, so Windows is the only requirement. It does still need the pack — the 3.4 GB of engine, IWADs and mods — which it fetches on first run.

First run

  • Unpack or install, then open the app.
  • It fetches 3.4 GB from the project's own storage and verifies every file against its hash. Already-correct files are skipped, so re-running is cheap.
  • Pick a game and hit launch.
Commercial IWADs are not included. DOOM2.WAD and Hexen.wad are id Software releases, so the pack refuses them rather than hosting them. Entries that need one will ask you to supply it.

Also works without the app

If you would rather not install anything, the launcher is just a local web server. Clone the repo and run python serve.py — it opens the same interface in your browser and launches games exactly the same way.
